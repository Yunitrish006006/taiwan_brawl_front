# 情侶元件配色與伴侶名稱

使用者於 2026-11-09 要求美化、可選色，並顯示「與〈伴侶名稱〉交往的第 N 天」，
取代早期只顯示天數的決策。手機「情侶天數 → 元件配色」提供玫瑰粉、薰衣草紫、
晴空藍、薄荷綠、奶油米與午夜深藍。圓角漸層、淡色圓形裝飾及大字天數；較高的
Android 元件另顯示裝飾愛心。名稱獨立一行、過長省略，天數仍維持可讀尺寸。

配色是裝置偏好，所有本機元件共用，不修改關係、不需伴侶同意；寫入成功才切換
預覽，失敗保留先前配色。登出不清除配色，但會清除關係日期及名字。
Android 已支援即時刷新；iOS 程式也使用獨立 App Group 外觀檔與 WidgetKit reload，
仍維持原 opt-in 與待 Xcode／簽章驗收界線。網頁不修改手機桌面偏好。

## 名稱資料界線

受驗證的 couples overview 從主庫目前伴侶的 profile 讀取可選 partnerName，
只在確認 active 及雙方仍可存取時提供。最多 80 Unicode code points、移除控制
字元。原生上限為 160 UTF-16 units；舊九欄 v1 快照仍可讀，缺名字時只顯示天數。
照片及憑證沒有加入快照。解除、封鎖／刪好友、登出及換帳號沿原 generation／
sequence 機制一起清除名字。readCounter 唯讀投影仍維持三欄、不包含名字。

繁體中文原生資源新增 zh-Hant script qualifier，配合 Pixel 7a 的 zh-Hant-TW
語言，避免元件繼續回退英文。長名字與大字級使用截斷／縮放，不會新增操作能力。

## 驗證

- Flutter：選色保存與重開、寫入失敗、連點序列化、長名字、大字級、6 色對比
  （兩端背景皆至少 4.5:1），以及名稱同步／登出清除；既有情侶頁操作回歸通過。
- Android：11 項 JVM 測試通過；最終 debug APK 已編譯並以保留資料方式更新手機。
- iOS：50 項 Foundation 檢查通過，含獨立外觀檔、名稱編解碼／清除及不擴張
  readCounter 投影；Swift 語法解析通過，不等同 WidgetKit 原生建置。
- 後端完整 Node／Vitest／workerd 測試通過；名稱只對目前伴侶提供並反映 profile
  變更。正式部署、資料庫 bindings 與 migrations 未修改。

Pixel 7a 實際操作：從好友側欄進入情侶頁、展開配色區，點選午夜深藍，確認
原生偏好保存、active 快照包含名字，回桌面觀察漸層與正確繁中名稱／天數，
無障礙描述也包含名稱。此為實際已登入關係，非合成名字。截圖僅留於當次暫存
目錄；含使用者名字與私人桌布，未加入 repository。沒有更改手機全域語言／時區。

這批不代表其他平台與完整省電／午夜排程矩陣均通過。iPhone 配色、WidgetKit
建置及簽章仍未驗收。手機依舊使用 Mac 的本機測試服務與 adb reverse。

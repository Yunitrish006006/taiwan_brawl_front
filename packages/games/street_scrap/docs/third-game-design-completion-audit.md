## 已執行的設計檢查與可重現命令

- `npm run design:audit`：111項字典、78條配方、78條policy與6束規則；唯一ID、合法引用／數量／占位、每階段至少一條成功來源、終端用途宣告。
- `npm run design:simulate`：一塊木板、兩份湯、第一份湯失敗、14天救助的有限樣本。成本／容器／簡化工作棋盤驗證，不宣稱全章物流或最優解。
- `npm run test:tools`：設計檢查器、內容編譯、語系覆蓋及指定情境 owner tests，含移除來源、錯誤ID／主材／尺寸、缺餐盒、滿瓶與空間反例。
- 工作區必要檢查：`node scripts/validate-workspace.mjs`、`npm test`、`node scripts/render-flutter-data.mjs`。它們證明工作區／檢查工具正常，不代替遊戲domain或Flutter測試。
